# Movies & Series Website

This project is a web application that allows users to browse and search for movies based on genres, ratings, and keywords. It fetches movie data from the OMDb API and provides an interactive user interface for exploring movie recommendations.

## Features

- **Search Movies**: Search for movies by title using the search bar.
- **Filter by Genre**: Select a genre to filter movies (e.g., Action, Comedy, Drama, etc.).
- **Sort by Rating**: Sort movies by their IMDb ratings in descending order.
- **Add to Favorites**: Mark movies as favorites and store them in the browser's local storage.
- **Responsive Design**: The application is designed to work seamlessly across devices.
